# Transformer Explainer: Interactive Learning of Text-Generative Models

## インストール
npm install

## ローカル確認

npm run dev
http://localhost:5173

## デプロイ (GitHub Actions)
このリポジトリには GitHub Actions が設定されており、`main` ブランチへ push すると自動的に GitHub Pages へデプロイされます。

### 初回設定
1. リポジトリを GitHub へ push します。
2. GitHub のページで **Settings > Pages** へ移動します。
3. `Build and deployment` > `Source` を **Deploy from a branch** に設定します。
4. `Branch` を **gh-pages** に設定して保存してください（最初のデプロイが成功した後に選択可能になります）。
